# 📖 About

This repository provides a **production-ready Playwright Automation Framework** built using Java, Cucumber, TestNG, and Maven.

The framework focuses on simplicity, readability, and maintainability without introducing unnecessary design patterns. It is suitable for beginners, QA Engineers, Automation Engineers, and enterprise automation projects.

# 🔥 Why Playwright?

## 1️⃣ Faster Execution

Playwright communicates directly with browsers, making tests significantly faster than traditional WebDriver-based automation.

---

## 2️⃣ Auto Waiting

No need for most explicit waits.

Playwright automatically waits for:

- Elements to appear
- Elements to become clickable
- Navigation
- Network idle

---

## 3️⃣ Reliable Tests

Built-in synchronization greatly reduces flaky tests.

---

## 4️⃣ Modern Browser Support

Supports:

- Chromium
- Chrome
- Edge
- Firefox
- WebKit

---

## 5️⃣ Better Debugging

Includes:

- Trace Viewer
- Screenshots
- Videos
- Console Logs

---

## 6️⃣ Simple Framework

Minimal code.

Less maintenance.

Easy onboarding.

---

## 7️⃣ BDD Ready

Supports readable Gherkin feature files using Cucumber.

---

## 8️⃣ CI/CD Compatible

Runs easily on:

- Jenkins
- GitHub Actions
- Azure DevOps
- GitLab CI
- Bamboo

---

## 9️⃣ Cross Browser Testing

Execute the same tests across multiple browsers.

---

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/imademethink/Automation_Java_Playwright_BDD_Cucumber_TestNG_Reporting_Maven.git
```

---

## Navigate to Folder

```bash
cd Automation_Java_Playwright_BDD_Cucumber_TestNG_Reporting_Maven
```

---

## Download latest stable chromedriver.exe file

```bash
https://googlechromelabs.github.io/chrome-for-testing/

Paste it in below folder
..\Automation_Java_Playwright_BDD_Cucumber_TestNG_Reporting_Maven\src\test\resources\chrome_driver\
```

---

## Install Playwright browser (embedded)

```bash
playwright install
```


---

## Install Dependencies

```bash
mvn clean install -DskipTests
```

---

## Execute Tests

```bash
mvn test
```

---

## Generate Report

HTML reports are automatically generated after execution with failure screenshot attached
..\Automation_Java_Playwright_BDD_Cucumber_TestNG_Reporting_Maven\target\HtmlReport.html
